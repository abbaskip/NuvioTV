# Nuvio ReSeq Beta 5

## Sports Hub
- The preview's empty-state message now follows the shared playback session, including streams selected in Live TV and catch-up replays. Paused, loading and reconnecting sources no longer invite users to select a game over existing video.
- The preview shows the current channel or replay title without changing event badges, controls or navigation.

## Live TV navigation
- Added a compact playlist selector to the left of Groups. Live TV still opens on Groups, and the group list remains continuous across playlists.
- Left from Groups focuses Playlists; Up/Down cycles playlists; Right returns to that playlist's groups; another Left opens the Nuvio sidebar.
- Hold Left while browsing the guide to expand the currently playing channel to fullscreen. The existing player and stream are retained; a held press does not also perform short-Left navigation. Normal Back and short-Left behavior remain available.
- Retained the existing per-Xtream-playlist Auto / MPEG-TS / HLS compatibility setting and its provider capability handling. Ordinary M3U and Stalker URLs are not rewritten. Find the setting under Settings → Live TV → Playlists → playlist actions. Changing it refreshes that playlist; it does not forcibly interrupt an already playing stream.

## Updates and downloads
- Added the previously prepared **Settings → About → Check for updates** button, including recovery of a dismissed update notification.
- Published universal, ARM32, ARM64, x86 and x86_64 APKs with the same application ID, version code and permanent release signing identity.
- Automatic updates now prefer the universal APK. ABI fallback rejects incompatible labelled APKs and distinguishes x86 from x86_64.
- Release tooling verifies native library contents, signing, package/version consistency and compatibility with the previous published signing certificate, then generates SHA-256 checksums. The GitHub Actions workflow repeats these checks for future releases.

## Validation and limits
- Broad Full Release unit suite: 2,805 passed, two skipped, zero failures; eight previously documented baseline tests excluded. After the final TV gesture/layout refinements, all 212 Live TV/Sports/updater tests passed. Python release-tool suite: 27 passed. Coverage includes Sports preview states, Xtream format negotiation, updater asset selection and APK native-library validation.
- On the connected ARM32 onn TV, universal and ARM32 in-place installation retained the app UID, account and playlists. Sports empty/playing states, playlist/group/side-menu navigation, normal Back, short Left, native long Left and a 700 ms no-repeat hold were exercised. Fullscreen return retained the current 9Gem stream while browsing elsewhere; player/codec logs showed no restart during the transitions. ARM64 and Intel variants receive package/native-library/signature checks; compatible ARM64 and Intel hardware is not available for installation tests.
- Live provider format changes were not forced during validation; format negotiation was tested automatically and the existing per-playlist control was checked on TV. IPTV playback and explicit stream-format availability depend on the provider. This update preserves existing catch-up negotiation and provider-specific behavior.

Beta builds may contain bugs. Built on NuvioTV and the IPTV integration under GPLv3; existing third-party notices and corresponding source remain included.
